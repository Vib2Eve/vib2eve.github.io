This repository contains only website resources. The research repository remains private.

The hosted workspace offers rule analysis and a visible model API configuration panel. Enter your own compatible API URL, model name, and key to run model analysis directly in the browser; the API must allow cross-origin requests (CORS). The optional local Python proxy supports providers that block browser requests. See the [connection guide](painting-u/README.md). Credentials are kept in page memory and excluded from exports.

The bilingual project homepage includes the complete 3:22 introduction video with inline playback and fullscreen controls. The H.264 MP4 is served directly with the website; visitors do not need a GitHub account.

The dialogue library contains 15 authored scenes in English and Chinese (30 language versions). Six multi-party scenes span 3, 4, and 5 actual speaking participants, including the wearer. It retains every original marked wearer fragment. Each scene can be opened in Painting U or downloaded as evidence JSON; full wearer sentences, scene labels, and discussion notes are excluded from that evidence. Segment times illustrate ordering rather than measured recovery timing.
